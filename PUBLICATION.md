# Publishing on GitHub / Публикация

1. Create the personal public repository `aion2-remote-play`. Upload this folder's contents (README files, `src`, `build.ps1`, `.gitignore`, licences and notices). Do not upload internal workspace folders or runtime logs.
2. Create a release tagged `v6.0.0` and attach the separate **Aion2RemotePlay-v6.0-windows-x64.zip** user archive. The source ZIP alone is not a runnable binary download.
3. Copy the desired text from `DESCRIPTION_RU.txt` / `DESCRIPTION_EN.txt` into your announcement. Describe v6 as requiring an interactive check until one has actually passed; built-in tests are not a game test.

1. Создайте личный публичный репозиторий `aion2-remote-play`. Загрузите содержимое этой папки: README, `src`, скрипт сборки, `.gitignore`, лицензии и уведомления.
2. Создайте релиз `v6.0.0` и приложите отдельный пользовательский **Aion2RemotePlay-v6.0-windows-x64.zip**. Исходники сами по себе не являются готовой программой.
3. Для объявления используйте DESCRIPTION_RU/EN. Не объявляйте новую v6 проверенной в игре до фактического теста.
